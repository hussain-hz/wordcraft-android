ما الجديد؟

- ترقية المحرك إلى 0.15.0 مع الحفاظ على أدوات التطبيق وإصلاحات العربية.
- تحسين الجداول وتخطيط الصفحات والأشكال والاستيراد والتصدير.
- إضافة إدارة حزم لغات التدقيق وفتح مستندات Word المحمية بكلمة مرور.
- تحسين الطباعة مع إبقاء الروابط فعالة في ملفات PDF المصدّرة.
- حفظ خيار عرض المراجعة وإعادة رسم المستند عند تبديله.
- تحسين البحث في التغييرات الظاهرة وتظليل نتائجه، مع حماية النص المحذوف من الاستبدال.
- تحسين ألوان المراجعة وإمكانية الوصول بالعربية والإنجليزية، مع الحفاظ على مظاهر التطبيق.

تمت تجربة النسخة واعتمادها.

لمزيد من التفاصيل [اضغط هنا](https://github.com/hussain-hz/wordcraft-android/blob/main/docs/RELEASE-0.0.10-ar.md).

What's new?

- Upgrade the engine to 0.15.0 while preserving Android tools and Arabic fixes.
- Improve tables, page layout, shapes, imports and exports.
- Add proofing language-pack management and password-protected Word document opening.
- Improve printing while preserving links in exported PDFs.
- Remember Display for Review and repaint the document when it changes.
- Improve search through visible tracked changes and match highlighting; never replace deleted text.
- Improve review colours and Arabic/English accessibility while retaining the app's themes.

Tested and approved.

For more details, [click here](https://github.com/hussain-hz/wordcraft-android/blob/main/docs/RELEASE-0.0.10-ar.md).
