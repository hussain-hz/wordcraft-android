# إصدار WordCraft 0.0.6

اعتمد المستخدم نسخة الاختبار 0.0.6-beta.2. هذا الإصدار ينقل التنفيذ نفسه إلى النسخة المستقرة، مع رقم النسخة النهائي 6990 وتوقيع الإنتاج ومعرّف الحزمة الأساسي. المحرك يبقى 0.11.0.

ما الجديد؟

- تصحيح المظهر الأسود: خلفيات سوداء للأشرطة والقوائم وورقة المستند، مع إبقاء الرمادي الداكن مميزًا وإضافة حد واضح لشريط الأدوات العائم.

- إضافة مظاهر جديدة للتطبيق: الملوّن والرمادي الداكن، إلى جانب الأبيض والأسود وإعداد النظام.
- تحسين نافذتي اختيار المظهر واللغة وعرضهما وسط الشاشة بتصميم موحّد.
- إضافة معاينات صغيرة للمظاهر وتمييز الخيار المحدد.
- تحسين تناسق ألوان الواجهة والأيقونات وشريط الحالة.
- تحسين دعم العربية والإنجليزية واتجاه العرض.
- تثبيت اسم التطبيق WordCraft


## التحقق ونطاق التغيير

اجتازت التغييرات في نسخة الاختبار 54 اختبارًا للمحرك و37 اختبار Kotlin وفحص Lint دون أخطاء (35 تحذيرًا و11 ملاحظة). تشمل الاختبارات فصل أسطح المظهر الأسود عن الرمادي، وعرض الورقة بالأسود والعودة للرمادي والأبيض مع ثبات النص العربي والإنجليزي. اجتاز APK الاختبار فحص توقيع الإنتاج والمعماريتين والتثبيت والتشغيل على محاكي x86_64، ثم اعتمده المستخدم. لم تُجرَ تعديلات وظيفية جديدة بين beta.2 والإصدار المستقر.

الملف المعتمد `WordCraft-0.0.6-release.apk` يدعم arm64-v8a وx86_64، ويرافقه ملف SHA256SUMS. يمكن تثبيته كتحديث فوق 0.0.5 ونسخ اختبار 0.0.6 الموقعة بالمفتاح نفسه. يُنشر كإصدار مستقر حتى يكتشفه فاحص التحديثات داخل التطبيق.
