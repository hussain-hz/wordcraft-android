# WordCraft 0.0.8

اعتمد المستخدم نسخة 0.0.8-beta.1 بعد تجربتها. يتضمن الإصدار المستقر التنفيذ نفسه، مع تحديث بيانات الإصدار إلى **0.0.8** ورقم الحزمة إلى **8990**. يبقى المحرك **0.11.0** مع إضافات Android وإصلاحات نسختنا.

## ما الجديد؟

- لوحة تعليقات جديدة مع الردود والتنقل بين السلاسل وحلّها وإعادة فتحها وحذفها، بألوان توافق المظهر المختار.
- تحسين عرض الهاتف وتباعد النص والتظليل وعلامات التغييرات المتعقبة.
- صفحة لعدّ الكلمات والأحرف والصفحات، مع خيارات تضمين مربعات النص والحواشي.
- تحسين قوائم الأنماط ولغات التدقيق والروابط، وإضافة لوحة تدقيق المستند.
- تحسين مؤثرات الصور والظلال والانعكاسات، والخطوط البديلة، وتسميات أدوات الوصول.
- استكمال تعريب الميزات الجديدة وتواريخ التعليقات ودعم اتجاه الواجهة في العربية والإنجليزية.
- الحفاظ على إصلاحات الكتابة العربية والمحاذاة والأرقام ١٢٣ و123 و۱۲۳، والمشاركة والتراجع والإعادة والمظاهر ومعارض الأدوات.

دُمجت تحديثات المشروع الأصلي حتى الالتزام `9beb31563db9901507abf96f7bca9a8572734474`. لم تُحذف أدوات الصور أو المخططات. التفاصيل الفنية ونتائج اختبارات الدمج موثقة في [تقرير نسخة الاختبار المعتمدة](TEST-0.0.8-beta.1-ar.md).

## التحقق

اجتازت نسخة الاختبار المعتمدة 2830 اختبار Rust، مع حالتين متجاهلتين وفق إعدادات الاختبارات، و43 اختبار Android وأربعة اختبارات للتعريب. أُعيد بناء الحزمة المستقرة الموقّعة وفحصها، مع إعادة اختبارات التعريب وفحص نتائج Android الـ43 الناجحة؛ أعاد Gradle استخدام نتائجها لأن مدخلات الاختبارات لم تتغير. نجح فحص Lint بلا أخطاء، مع 36 تحذيرًا و13 ملاحظة. لم يُعد تشغيل مجموعة Rust الكاملة لهذا التغيير في بيانات الإصدار فقط؛ جرى بدلًا من ذلك التحقق من التطابق الكامل لملفات المحرك والموارد الـ38 داخل الحزمة مع النسخة المعتمدة.

تستخدم الحزمة معرّف التطبيق وتوقيع الإنتاج نفسيهما، وتدعم arm64-v8a وx86_64، ويمكن تثبيتها كتحديث فوق النسخ السابقة. يتوفر الإصدار المستقر عبر التحقق من التحديثات داخل التطبيق.
